# Журнал сессий

Заполняется в конце каждой сессии. Цель — чтобы новая сессия на другой модели продолжила работу,
не читая предыдущую переписку.

## Протокол передачи между сессиями

1. **Одна сессия — одна модель.** Модель выбирается в пикере Freebuff до старта; изнутри разговора её сменить нельзя.
2. **Старт новой сессии:** «прочитай `work/SESSION_LOG.md`, `work/DECISIONS.md` и `work/PLAN.md`, продолжай с шага N моделью M».
3. **Конец сессии:** дописать запись по шаблону ниже и обновить чек-боксы в `PLAN.md`.
4. **Правило владельца:** код пишется только по прямой просьбе. Документы — можно.
5. **Если сессия оборвалась** (лимит, fair-use, сбой) — запись всё равно дописывается, с пометкой «оборвано на …».
6. **Что не переносить в журнал:** длинные рассуждения, фрагменты кода, переписку. Только факты, решения и следующий шаг.

## Шаблон записи

```
### Сессия N — ДД.ММ.ГГГГ — модель: <имя> — шаг: <номер>

Сделано:
- …

Проверено:
- …

Решения (если есть, продублировать в DECISIONS.md):
- …

Трогались файлы:
- …

Осталось / следующий шаг:
- …

Следующая модель: <имя> — почему
```
